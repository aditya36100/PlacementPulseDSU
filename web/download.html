PlacementPulse

Live placement updates from your college groups, with instant phone alerts.

Download for Android (APK)

How to install

  1. Tap Download. If Chrome says the file may be harmful, tap Download anyway.
  2. Open the file. If asked, allow Install unknown apps for Chrome.
  3. If Play Protect warns, tap Install anyway.
  4. Open PlacementPulse, sign in, and allow notifications.
Prefer not to install? Open the web version and use your browser’s “Add to Home screen”. Android only for now.
